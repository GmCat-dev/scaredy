# Security

If you find a security problem in Scaredy GmCat (for example a way to read someone's file without the full link, to
join or take over someone else's link, to make the relay keep data, or to run code on scaredy.gmcat.io), please report
it privately:

**GitHub → this repository → Security → "Report a vulnerability".**

Please include steps to reproduce. We'll reply as soon as we can and credit you if you'd like.
Please don't test against other people's links, and don't run load tests against scaredy.gmcat.io.

Out of scope: anything that needs the full private link (the link *is* the key), denial of service, the fact that
Direct mode shows each side's IP address to the other, and the Short link key passing through our server (both are by
design and explained on the page).
